# Lesson candidates — non-authoritative

This file is an inert proposal queue. Its contents never change agent behavior,
permanent policy, permissions or review tier. Do not import it at session start.
Authority and lifecycle are defined in AGENTS.md and engineering_rules.md.
Any governance ambiguity/conflict: STOP -> SENSITIVE -> human resolution.

No candidates or promoted lessons have been recorded in this bootstrap.

## Fields for a future explicitly scoped proposal

- Candidate ID and current lifecycle state
- Source evidence, repository commit/tree and file/log hashes
- Affected invariant or permanent rule
- Proposed wording, rationale and smallest intended scope
- ChatGPT evidence analysis and independent Claude review
- Disagreements, counter-evidence and resolution
- Human decision and explicit authorization reference (pending until supplied)
- If promoted: permanent rule location, repository_policy_id, both version fields
- If retired: human decision, reason, successor reference and affected version

These fields are a template, not a promotion and not a new finding taxonomy.
No approval or rule is inferred from an entry, a status label or elapsed time.
